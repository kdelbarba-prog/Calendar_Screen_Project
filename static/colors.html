Every color from config/colors.yaml, shown the way the dashboard draws it: a multi-day bar, a confirmed event, and a tentative event (dashed edge). Edit the swatches, add colors, then copy or download the YAML at the bottom. This page never writes to the Pi; saving is a manual step (see the instructions below).

colors.yaml

To apply changes on the Pi: replace /calendar/config/colors.yaml with the copied or downloaded text, then run sudo systemctl restart dashboard.service and reload the dashboard. A calendar uses a color through its color: name in config/config.yaml, so deleting or renaming a color that a calendar uses will stop the dashboard from loading. The page reads the palette the dashboard last loaded from /data.json; it shows what is live right now.
